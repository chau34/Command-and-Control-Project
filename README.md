# Command and Control Project

## Files
- `atest/combined.jpg`: zip file containing cat image and helloworld.py <br><br>

- `vtest/get_backup.py`: python file to get backup images coming from port
- `vtest/get_backup.cpp`: cpp version of get_backup.py
- `vtest/get_backup_raw.cpp`: raw cpp version of get_backup.cpp, untested, do not use
- `vtest/print_backups.sh`: script to unzip and run python files such as helloworld.py <br><br>

- `attacker.py`: list of commands to send from attacker machine
- `backup`: the compiled version of get_backup.cpp for CENTOS 7
- `cat.jpg`: original cat file with no python attached <br><br>

- `check_name.py`: currently not used, authenticate through file names idea
- `encoder.py`: file for obfuscation
- `generate_names.py`: currently not used, generate file names for authentication idea <br><br>

- `helloworld.py`: test file that prints "hello world" <br><br>
